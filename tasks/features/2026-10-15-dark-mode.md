# Feature: Dark mode

- **Status:** Planned
- **Requested:** 2026-10-15
- **Priority:** Medium · **Effort:** Medium
- **Depends on:** none
- **Spec file:** `tasks/features/2026-10-15-dark-mode.md`
- **Related master task items:** `tasks/TASKS.md` Phase 13

## 1. Summary

A dark theme that follows the system setting or a manual choice, remembered per person.

## 2. Goals and non-goals

- Goal: Light, Dark and System options in the user menu
- Goal: All screens, charts and the editor readable in dark
- Goal: No flash of the wrong theme on load
- Not in this change: Per-company custom themes

## 3. Behaviour (the spec)

| Who (role / permission / data scope) | Can do | Cannot do |
|---|---|---|
| Any signed-in person | Choose a theme; the choice is remembered | - |

Rules (cite `WORKFLOW.md` where one applies, and new rules this feature introduces):

- Theme stored in `localStorage` and on the user record so it follows them across devices
- Respect `prefers-color-scheme` for System
- Colours come only from Tailwind tokens (`darkMode: "class"`)

## 4. Data

Add `users.theme` (nullable string: light, dark, system). Additive.
